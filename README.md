# 스팀 찜 목록 카드 메이커

스팀 찜 목록 공유 링크를 붙여넣으면 게임들을 카드로 정리해 **사진(PNG/JPG)으로 저장**해 주는 웹앱입니다.

카드 한 장에는 게임 이미지, 게임 이름, 찜한 날짜가 들어갑니다. 기본 배치는 가로 3개이고
그 아래로 계속 이어집니다.

## 실행

Node.js만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
node server.js
```

브라우저에서 <http://localhost:3000> 을 열고, 찜 목록 주소를 붙여넣은 뒤 **불러오기**를 누르세요.

```
https://store.steampowered.com/wishlist/profiles/76561199260592582/?st=...
```

다음 형태도 모두 인식합니다.

- `store.steampowered.com/wishlist/id/<커스텀URL>/`
- `steamcommunity.com/profiles/<프로필ID>/wishlist`
- `steamcommunity.com/id/<커스텀URL>/wishlist`
- 프로필 ID(17자리 숫자)나 커스텀 URL 이름만 입력

## 기능

| 설정 | 내용 |
| --- | --- |
| 가로 개수 | 1~6개 (기본 3개) |
| 정렬 | 찜한 날짜 최신순·오래된순, 스팀 우선순위, 이름순 |
| 테마 | 스팀 블루 / 미드나이트 / 라이트 |
| 표시 항목 | 상단 영역(프로필 사진·닉네임 각각), 찜한 날짜, 출시일 |
| 저장 해상도 | 1배 / 2배 / 3배 |
| 파일 형식 | JPG(가벼움) / PNG(무손실) |
| 게임 선택 | 목록에서 원하는 게임만 체크해서 포함 |

오른쪽 미리보기가 곧 저장될 이미지입니다. 화면에 보이는 그대로 파일로 나옵니다.

**카드 색은 게임 이미지에서 뽑아냅니다.** 아트가 파랗면 파란 카드, 붉으면 붉은 카드가
되어 목록 전체가 알록달록한 모자이크처럼 보입니다. 이미지를 작게 줄여 픽셀을 훑되
채도가 있는 픽셀에 가중치를 줘서, 단순 평균을 냈을 때 나오는 잿빛을 피합니다.

**프로필 사진과 이름은 따로 끌 수 있습니다.** 찜 목록을 공개적으로 공유하면서 계정은
드러내고 싶지 않을 때 쓰면 됩니다. 이름을 끄면 제목이 "스팀 찜 목록"으로 바뀌고,
저장 파일 이름에도 닉네임이 들어가지 않습니다.

## 배포

**<https://wishlist.quest>** 에서 서비스 중입니다.

Lambda가 앱을 돌리고, 앞에 CloudFront가 붙어 있습니다. CloudFront가 게임 이미지를
엣지에 캐시하기 때문에 두 번째 방문부터는 Lambda를 거의 호출하지 않습니다.

```
사용자 → wishlist.quest → CloudFront → Lambda 함수 URL
```

코드를 고친 뒤 다시 올리려면:

```bash
powershell -File deploy.ps1
```

빌드 → 업로드 → 반영 대기 → 헬스체크까지 한 번에 합니다.
최초 구축 과정과 겪은 함정들은 [aws/setup.md](aws/setup.md)에 정리해 두었습니다.

## 구조

```
router.js          요청 처리의 알맹이 (스팀 조회 · 이미지 프록시 · 정적 파일)
server.js          로컬 실행용 껍데기
lambda.js          AWS Lambda용 껍데기
build.ps1          배포 zip 생성
deploy.ps1         빌드 + 업로드 + 확인
public/index.html  화면
public/style.css   설정 패널 스타일
public/app.js      캔버스 렌더링 · 저장
```

`router.js`가 로컬과 Lambda 양쪽에서 그대로 쓰이므로, 로컬에서 되면 배포본에서도 됩니다.

### 왜 서버가 필요한가

1. **CORS** — 브라우저에서 스팀 주소를 직접 부르면 차단됩니다.
2. **캔버스 오염** — 다른 출처의 이미지를 캔버스에 그리면 `toBlob()`이 막혀 저장이 불가능합니다.
   그래서 스팀 CDN 이미지를 서버가 대신 받아 같은 출처로 넘겨줍니다.

스팀 API 키는 필요 없습니다. 링크에 들어 있는 프로필 ID로 공개 찜 목록을 읽습니다.

### 사용하는 스팀 엔드포인트

- `IWishlistService/GetWishlist` — appid와 찜한 날짜
- `IStoreBrowseService/GetItems` — 게임 이름·이미지·출시일 (50개씩 묶어 조회)
- `steamcommunity.com/...?xml=1` — 닉네임·아바타, 커스텀 URL → 프로필 ID 변환

## 찜 목록을 못 불러온다면

찜 목록이 비공개면 읽을 수 없습니다. 스팀에서
**프로필 → 개인정보 보호 설정 → 게임 세부 정보**를 `공개`로 바꾼 뒤 다시 시도하세요.

## 참고

- 조회 결과는 10분간 서버 메모리에 캐시됩니다.
- 게임이 많고 해상도가 3배면 이미지가 매우 커집니다. 공유용이라면 JPG를 권합니다.
  (39개 기준 2배 해상도에서 JPG 약 2.6MB, PNG 약 12MB)
